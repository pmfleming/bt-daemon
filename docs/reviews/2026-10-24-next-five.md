# Next five quality improvements

Baseline: `b759c97`, with the two pre-existing recovery-test edits left uncommitted.
Tool: the pinned local executable at `target/next-five/rqlens`. Artifacts and logs
are under `target/next-five`; the repository's quality thresholds are unchanged.

## 1. Bounded, linear vendor framing

`src/framing.rs` now scans each incoming byte once, retains only a bounded encoded
body, and reuses that buffer. Previously it appended the entire input and repeatedly
drained/searched a vector; complete oversized frames bypassed the incomplete-frame
limit. The limit now applies regardless of fragmentation/coalescing. The existing
boundary (opening delimiter plus body <= 4096 bytes) is preserved. Shared HDLC
flags, Sony empty-frame rejection, and noise/corruption recovery remain supported.

One shared boundary matrix covers both delimiter styles, four lengths around the
limit, three chunk sizes, and recovery. Removed duplicated vendor-specific size
checks; retained their independent wire vectors and payload validation tests.

Validation: 67 unit + 2 integration tests passed, one existing ignored experiment;
Clippy with `-D warnings`, formatting and diff checks passed. RQLens reports
`DelimitedFrames::push` Halstead effort 49,535 -> 35,652. Its explicit bounded-state
handling increases cognitive/cyclomatic complexity from 6/5 to 11/7; this stage
prioritizes a real resource-bound defect and linear processing, not lower branch
counts at the expense of validation. No throughput benchmark is claimed.

## 2. Strict Maestro protobuf boundaries

The tenth varint byte previously lost overflowing high bits during a shift. The
reader now handles the first 63 bits and validates the final bit separately.
Field keys must fit the protobuf 32-bit key encoding and have a nonzero field
number. Checked slice splitting centralizes truncated-field handling. Unknown
legal fields and non-minimal in-range varints retain their previous compatibility.

A boundary matrix exercises integer extremes, overflow through real HDLC decoding,
zero/oversized field numbers, truncated wire values, unsupported wire types, and
unknown fixed64 fields. Validation: 68 unit + 2 integration tests passed, one
existing ignored experiment; Clippy, formatting and diff checks passed. Additional
validation does not reduce parser complexity: `read_varint` cognitive/cyclomatic
is 3/4 -> 3/5. This is a correctness fix, not a claimed metric reduction.

## 3. Local, deterministic audio snapshot assembly

Registry assembly now delegates per-device normalization to `AudioDevice::finalize`.
Codec agreement scans borrowed strings instead of allocating a hash set; unknown
readings are ignored and ambiguous readings never overwrite the configured codec.
Endpoint ties use object IDs, profile ties use profile indices, and device sorting
caches lowercase names with an ID tie-breaker. Removed two fixture-only clones by
moving ownership through the same probe-state boundary as production.

Tests cover equal-name endpoint ordering, sink/source defaults, internal-node codec
exclusion, missing/conflicting/consistent codec evidence, absent/unknown active
profiles, repeated normalization, profile ties, device ties and empty endpoints.
Validation: 69 unit + 2 integration tests passed; one existing ignored experiment;
Clippy, formatting and diff checks passed.

The original finalizer's cognitive complexity 11 becomes 3 in assembly, 5 in
per-device normalization and 0 in codec agreement (sum 8). Combined Halstead effort
falls from 63,992 to 51,424. Combined cyclomatic complexity rises 8 -> 11, including
the added function-entry counts and checked optional codec; this is not presented
as a reduction in every complexity aggregate.

## 4. Testable, fail-closed profile-change sequencing

A single `ProfileChange` owns identity, serialized parameters, requested index,
write-attempt state and the existing completion latch. Callbacks share it instead
of independently cloning bytes, identity and completion/written flags. A missing
proxy or invalid parameter is now a terminal error, not a silently skipped write
marked as written. Existing terminal errors prevent later writes; identity changes
still invalidate an earlier success. Subscriptions are attached to every binding,
including bindings created after a write, without replaying the command.

The boundary test uses real property dictionaries and serialized SPA parameters
with an injected writer and a local main loop (no PipeWire server). It exercises
pre-write notifications, missing identity, one write despite repeated callbacks,
wrong event types/indices, missing parameters, matching confirmation, late identity
failure, local write failure, pre-existing core/removal failure, no replay, and
unrepresentable profile indices. This does not prove physical hardware behavior.

Validation: 70 unit + 2 integration tests passed, one existing ignored experiment;
Clippy, formatting and diff checks passed. `apply_profile` cognitive complexity
10 becomes 0 in binding glue plus 4/2 in the decision methods (sum 6). Their combined
Halstead effort falls 58,221 -> 43,492; combined cyclomatic complexity rises 10 ->
14 with the added function boundaries and failure checks.

## 5. Generation-fenced vendor connections

Every pending connect has an attempt ID. A failure only changes the matching
attempt; disconnect invalidates pending work without releasing a live reader's
ownership. Missing stream callbacks now expire into exponential backoff instead
of repeatedly issuing connects at a fixed rate. Failure counters saturate, attempt
IDs never wrap, and handler cleanup finishes before a replacement stream is allowed.
Unused `Retry` copy/clone implementations were removed.

Retry timing now uses Tokio's monotonic clock. Deterministic paused-time tests
replace manual timestamp injection and cover the six busy retries, exact retry
boundaries, maximum counters, 59/60-second stable-stream behavior, stale failures,
same-clock disconnect/reconnect generations, unrelated peers, accepted streams,
missing callbacks, non-postponing polling and attempt-ID exhaustion.

Validation: 71 unit + 2 integration tests passed, one existing ignored experiment;
Clippy, formatting and diff checks passed. `Links::begin` cognitive/cyclomatic is
2/4 -> 3/6: the additional expiry/generation checks are intentional safety work.
